# LOS14.1 正常内核 lcm_init / lcm_resume / lcm_resume_power 逐指令完整反汇编

来源：`lineage-14.1-20260822-UNOFFICIAL-h3000s/boot.img`（3.18.35，2021，功能全好）
驱动：`nt35523_fhd_vdo_boe`，LCM_DRIVER @0xffffffc000f10ea8
VA→file 偏移：`fileoff = VA - 0xffffffc000080000`
全局区 `x19 = 0xffffffc00122f740`（LCM 驱动运行时变量区）
GPIO helper `0x4581bc(gpio, val)` = `mt_set_gpio_mode(gpio)` → `mt_set_gpio_dir(gpio, val!=0)` → `mt_set_gpio_out(gpio, val!=0)`
三个 GPIO 全局变量：`[x19+0xe0]=rst`、`[x19+0xe4]=enp`、`[x19+0xe8]=enn`
（证据：日志格式串 `=====nt35523====rst = %d, enp = %d, enn = %d`，参数正是 e0/e4/e8）

## 一、lcm_init @0xffffffc000458344（31 条指令）

```
458344 stp x29,x30,[sp,#-0x20]!
458348 adrp x0, 0xd12000          ; rodata 页
45834c mov x29,sp
458350 str x19,[sp,#0x10]
458354 adrp x19, 0x122f000
458358 add x19,x19,#0x740         ; 全局区
45835c add x0,x0,#0xb90           ; "nt35523 lcm_init() id = %d enter"
458360 ldr w1,[x19,#0xd8]         ; ← 硬件 vendor id
458364 bl printk
458368 ldr w0,[x19,#0xd8]
45836c cmp w0,#1
458370 b.eq 0x4583c0              ; ★ id==1 → 表1(291项)
458374 ldr w0,[x19,#0xdc]         ; ← GPIO lcd_id 脚号
458378 bl mt_set_gpio_mode(w0)
45837c bl mt_get_gpio_in(w0)      ; 读 ID GPIO 电平 → w0
458380 mov w19,w0
458384 mov w1,w0
458388 adrp x0,0xd12000
45838c add x0,x0,#0xbc8           ; "lcd_id val = %d"
458390 bl printk
458394 cbz w19, 0x4583e0          ; ★ GPIO==0 → 表2(23项)
458398 cmp w19,#1
45839c b.ne 0x458400              ; 其它 → 报错退出
4583a0 adrp x0,0xf0e000
4583a4 mov w1,#0x6d               ; ★ 109 项
4583a8 add x0,x0,#0xb90
4583ac add x0,x0,#0x470           ; 表3 @0xf0ef00
4583b0 bl push_table(x0, 0x6d)
4583b4 ldr x19,[sp,#0x10]
4583b8 ldp x29,x30,[sp],#0x20
4583bc ret

0x4583c0: adrp x0,0xf09000; mov w1,#0x123(291); add x0,#0x690; add x0,#0x120
          → push_table(表@0xf097b0, 291)   ← 291项表
0x4583e0: adrp x0,0xf0d000; mov w1,#0x17(23); add x0,#0xa90; add x0,#0xef8
          → push_table(表@0xf0e988, 23)    ← 23项BOE表
0x458400: 打印 "no lcm id" 报错，不推表
```

**init 真实行为**：根据两级 ID 选三张表之一推：
1. vendor id(x19+0xd8)==1 → 291 项表
2. 否则读 GPIO lcd_id：==0 → 23 项表；==1 → 109 项表；其它 → 不推表报错

## 二、lcm_resume @0xffffffc000458420（58 条指令）

```
; ---- 日志 ----
458424-458440  printk("lcm_resume() enter")
45844c-458468  printk("=====nt35523====rst=%d, enp=%d, enn=%d",
                       [e0]=rst, [e4]=enp, [e8]=enn)

; ---- 复位脉冲序列（此时 VGP 供电已由 resume_power 打开）----
45846c ldr w0,[x19,#0xe4]      ; enp
458470 mov w1,#1
458474 bl gpio_helper          ; enp = 1
458478 ldr x1,[x19,#0x20]      ; mdelay 函数指针
45847c mov w0,#2
458480 blr x1                  ; delay 2ms

458484 ldr w0,[x19,#0xe8]      ; enn
458488 mov w1,#1
45848c bl gpio_helper          ; enn = 1
458490 ldr x1,[x19,#0x20]
458494 mov w0,#0xf
458498 blr x1                  ; delay 15ms

45849c ldr w0,[x19,#0xe0]      ; rst
4584a0 mov w1,#1
4584a4 bl gpio_helper          ; rst = 1
4584a8 ldr x1,[x19,#0x20]; mov w0,#5; blr x1    ; delay 5ms

4584b4 ldr w0,[x19,#0xe0]      ; rst
4584b8 mov w1,#0
4584bc bl gpio_helper          ; rst = 0
4584c0 ldr x1,[x19,#0x20]; mov w0,#2; blr x1    ; delay 2ms

4584cc ldr w0,[x19,#0xe0]      ; rst
4584d0 mov w1,#1
4584d4 bl gpio_helper          ; rst = 1
4584d8 ldr x1,[x19,#0x20]; mov w0,#0xf; blr x1  ; delay 15ms

; ---- 日志 + 调用 init ----
4584e4-4584f4 printk("=====nt35523====")
4584f8 bl 0x458344             ; ★★ 调用 lcm_init() —— resume 内二次初始化推表
4584fc ldp...
458504 ret
```

**resume 真实行为**：
1. `enp=1` → 2ms
2. `enn=1` → 15ms
3. RST: 高5ms → 低2ms → 高15ms
4. **调用 init()**（按 vendor id / GPIO id 选表推）——这是之前完全遗漏的关键！

## 三、lcm_resume_power @0xffffffc00045817c（16 条指令）

```
45817c stp x29,x30,[sp,#-0x10]!
458180 adrp x1,0xb07000
458184 adrp x0,0xd12000
458188 add x1,x1,#0x7f8
45818c mov x29,sp
458190 mov w2,#0x44d             ; 行号 1101
458194 add x1,x1,#0x30
458198 add x0,x0,#0xb40          ; "====8176===="
45819c bl printk
4581a0 bl 0x458840               ; ★ lcm_vgp_supply_enable()（打开 VGP 电源）
4581a4 adrp x1,0x122f000
4581a8 mov w0,#0x14              ; 20
4581ac ldr x1,[x1,#0x760]        ; mdelay 函数指针
4581b0 blr x1                    ; delay 20ms
4581b4 ldp...
4581b8 ret
```

`0x458840` = `lcm_vgp_supply_enable()`：
```
458840 stp...
458844 adrp x0,0xd12000; add x0,#0xe98  ; "LCM: lcm_vgp_supply_enable"
458850 bl printk
458854 adrp x1,0x122f000
458858 mov w0,#0
45885c ldr x1,[x1,#0x830]        ; regulator 指针
458860 cbnz x1, 0x45886c         ; 若 regulator 存在 → enable
458864 ret
```

**resume_power 真实行为**：打开 VGP(1.8V) LDO regulator → 等 20ms。

---

## 完整唤醒时序（框架调用顺序）

```
1. lcm_resume_power():  VGP 1.8V regulator ON → 20ms
2. lcm_resume():
   a. enp=1 → 2ms      (VSP+ 升压使能)
   b. enn=1 → 15ms     (VSN- 升压使能)
   c. RST 高5ms → 低2ms → 高15ms
   d. lcm_init(): 按 id 选表推（通常 23 项 BOE 表）
```

---

## 与我们的内核逐项对比（关键差异）

| 环节 | 正常内核 | 我们的内核 |
|---|---|---|
| resume_power | VGP regulator ON + **20ms** | 只拉 1V8 GPIO + 12ms |
| resume 供电顺序 | **enp↑2ms → enn↑15ms**（先供电） | 我们 stock 版先 RST 后 VSP/VSN |
| RST 脉冲 | 高5 → 低2 → 高**15**ms | 高5 → 低2 → 高**25**ms |
| resume 末尾 | **调 init() 二次推表** | 直接 push_table 一次，不调 init |
| 表选择 | vendor id + GPIO id 三级选表 | 固定 23 项，无 ID 判断 |
| rst_new | 无此概念 | 有但与主 RST 同为 gpio1016（空操作） |

**最可疑的三个根因差异**：
1. resume 里**调 init()**（二次初始化）——我们完全没有
2. RST 第三段 **15ms vs 25ms**
3. resume_power 用 **regulator**（VGP）而非 GPIO 直接拉 1V8
